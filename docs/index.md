# Quay Provider

The Quay provider manages resources on [Quay.io](https://quay.io) or a self-hosted
[Red Hat Quay](https://www.redhat.com/en/technologies/cloud-computing/quay)
instance via the Quay REST API.

## Authentication

The provider authenticates using an OAuth application token. Encrypted
passwords generated from the CLI password page are not accepted by the API.

To create a token:

1. Log in to your Quay instance as an organisation admin.
2. Navigate to the organisation, open the **Applications** tab, and create a
   new application.
3. Click **Generate Token** and select the scopes your configuration requires:
   - `org:admin` — create and manage organisations
   - `repo:admin` — create and manage repositories and their notifications
4. Copy the token that is displayed. It is shown only once.

Set the token via the `QUAY_TOKEN` environment variable to avoid storing
credentials in your configuration files.

## Example Usage

```terraform
terraform {
  required_providers {
    quay = {
      source  = "quay/quay"
      version = "~> 0.2"
    }
  }
}

provider "quay" {
  # Defaults to https://quay.io. Override for self-hosted instances.
  # Can also be set via the QUAY_URL environment variable.
  url = "https://quay.io"

  # Required. Can also be set via the QUAY_TOKEN environment variable.
  token = var.quay_token
}

variable "quay_token" {
  description = "Quay.io OAuth token"
  type        = string
  sensitive   = true
}
```

## Schema

### Optional

- `timeout` (Number) HTTP client timeout in seconds. Defaults to 30. Set to 0 to disable the timeout. Can also be set via the QUAY_TIMEOUT environment variable.
- `token` (String, Sensitive) OAuth bearer token for authenticating with the Quay API. Can also be set via the QUAY_TOKEN environment variable.
- `url` (String) The base URL of the Quay instance. Defaults to https://quay.io. Can also be set via the QUAY_URL environment variable.
