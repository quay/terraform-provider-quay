# Security Policy

## Supported Versions

Only the latest released version of this provider receives security fixes.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅        |
| Older   | ❌        |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

To report a vulnerability, use GitHub's private
[Security Advisory](https://github.com/quay/terraform-provider-quay/security/advisories/new)
feature. This allows us to discuss, fix, and disclose the issue responsibly.

Please include as much of the following information as possible to help us
understand and reproduce the issue:

- A description of the vulnerability and its potential impact
- The affected version(s)
- Steps to reproduce or a proof-of-concept
- Any suggested mitigations (optional)

You can expect an initial response within **7 days**. We will keep you informed
as we work toward a fix and coordinate a disclosure timeline with you.

## Disclosure Policy

Once a fix is available we will:

1. Release a patched version
2. Publish a GitHub Security Advisory crediting the reporter (unless you prefer
   to remain anonymous)
